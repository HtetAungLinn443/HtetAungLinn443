### 🏪 PhiLo POS Co-Founder & CTO
- 🚀 Architect and lead developer of **[PhiLo POS](https://philo.asia)**, a multi-platform point-of-sale and inventory platform built for Myanmar businesses. It runs on **Android, iOS, Windows, macOS and Web**.
- 🧩 I own the whole product suite:
  - **Laravel API**, the core backend with MySQL, Sanctum auth, Google/Apple sign-in, subscriptions and scheduled jobs
  - **POS app** (React + Ionic + Capacitor), with offline-first sales, open tickets, credit sales and shift close
  - **Admin panel** and the **philo.asia** website (Next.js), with reports, stock transfer, multi-branch and a Help Center with an AI assistant
  - **Manager app** (React Native + Expo), with dashboard, stock, reports, subscription payment and barcode printing
  - **KDS kitchen display** (Capacitor), which receives orders from POS over the local network
  - **Electron** desktop builds
- 🖨️ I built ESC/POS printing over **BLE, USB and network** thermal printers, plus laser printing, including Myanmar Unicode rendering.
- 🤖 I set up automation such as a Telegram bot for subscription payments and an expiring-subscription digest.
- 🔐 I take security seriously: dependency audits, token verification, rate limiting, CORS and proxy hardening, and timely server patching.

### 🌏 Other work
- 📈 **Ravus AI FX: Ghost Candle Projection.** I built the frontend for an AI forecasting chart that shows the predicted next candle with Q10/Q50/Q90 ranges on a TradingView-style chart.
- 🎤 **Raveon Live** (in development, Singapore client). It's an event platform with Super Admin and Organization panels, a mobile app for gifts and song requests, and a **Projection app** that controls content across multiple LED screens from one canvas. There's also a mini version for KTV venues and small events.

### 🛠️ DevOps
- GitHub Actions CI/CD, Docker, Nginx, Ubuntu VPS management, mail server setup (DKIM/SPF) and network tunneling
- App Store, Play Store and TestFlight releases, plus OTA updates
